# 英语星球 Beta：超市每日菜单

超市按家庭时区的本地日期轮换 14 个菜单。当天进入或重新开始，菜单保持一致；相邻两天不同，14 天后循环。每个菜单有 4 样食材。孩子必须先听辨并找齐食材，才可进入对话。现有 `menu_code` 为空的旧会话继续使用原来的苹果、香蕉、牛奶、面包流程。

会话保存 `menu_code`，所以跨过午夜也不会在中途换食材。伙伴开场用过去时询问昨天吃过的东西；若昨天完成过超市探索，会提到昨天的菜单。结账后用将来时询问明天想吃什么，页面提供 3 个选择。孩子点击选择后，文字会作为一轮对话发送并记录；选择按孩子和次日本地日期保存，明天进入超市时使用。孩子不选也可以结束会话；次日采用自动轮换菜单。

配置了 Qwen 聊天密钥且家长允许 AI 时，伙伴携带今日菜单、开场话、近期对话和当前任务生成自然的简短美式英语回复。未配置、禁用或模型不可用时采用本地模拟回复。密钥不写入仓库。英语星球的英语播放速度设为原来的 90%；浏览器语音回退优先选美式英语音色。

## 迁移与回滚

迁移 `2026_10_26_180000_add_menu_to_english_beta_sessions.php` 仅增加可空 `menu_code` 和 `english_beta_menu_choices` 表。回滚该迁移会删除孩子对明天菜单的选择；会话、对话、词汇、任务记录保持。代码回滚后旧版本忽略新字段；如需撤销数据库迁移，先备份 `english_beta_menu_choices`，再运行该迁移的 `down()`。

## 验证范围

`EnglishBetaTest` 覆盖菜单跨日变化、食材收集门槛、明天选择持久化、次日菜单与昨天回顾、Qwen 上下文，以及旧会话兼容。前端语音和卡片测试覆盖播放及步骤切换。实际孩子账号的设备语音与模型表现仍应在真实设备上体验确认。
