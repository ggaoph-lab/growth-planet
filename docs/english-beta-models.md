# 英语星球 Beta · 模型与省用量

## 要在阿里云百炼开通的模型

控制台：https://bailian.console.aliyun.com/ → 模型广场（与家长 AI 里 Qwen API Key 同一地域，一般为华北 2 北京）。

| 用途 | 推荐模型 ID | 说明 |
| --- | --- | --- |
| 伙伴文字对话 | **`qwen-flash`** | 替代已下线的 `qwen-turbo`；更快更省。备选 `qwen3.8-flash` |
| 录音转写 / 发音识别 | **`qwen3-asr-flash`** | 仅点「说话」时调用 |
| 伙伴英语朗读 | **`qwen3-tts-flash-realtime`** | WebSocket 实时合成，音色 **Jennifer**；缓存命中不重复合成 |

不要再搜 `qwen-turbo`：官方已列入下线名单，模型广场经常搜不到。离线版 `qwen3-tts-flash` 与 realtime 额度不互通。

同一 DashScope / 百炼 API Key 即可。ASR 若在子业务空间，需单独授权。

额度耗尽且开启「免费额度用完即停」时，朗读会快速失败并回退浏览器语音。

## 省 Token 方案（默认 `token_mode=frugal`）

1. **对话**：听辨、点餐、结账等剧本回合本地回复，不调对话模型。
2. **对话（偶发 AI）**：仅开放闲聊才调用 `qwen-flash`；短提示；历史最多 2 轮；`max_tokens≈48`。
3. **转写**：默认关闭；开启后一次录音一次转写。
4. **朗读**：服务端缓存；页面只预热下一题听辨句与问候；超时约 1.6s 用浏览器先读。
5. **家长开关**：不需要神经对话就关「允许 AI 对话」；不需要麦克风就关「允许语音伙伴」。

`full` 模式每次伙伴回复都可走 AI（历史 6 轮、`max_tokens≈80`），费用更高。
