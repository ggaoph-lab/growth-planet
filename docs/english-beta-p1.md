# 英语星球 Beta · P1

P1 在 P0 的独立入口、表和家庭开关上扩展超市场景，不修改旧英语探索与奖励账本。

## 学习链路

- 同一儿童一次只续接一个未到时会话；刷新儿童页面后从服务端恢复对话和任务。按家长设置的时长到期后关闭旧会话，再开始新会话。
- 听辨题播放英语商品名称，孩子点选商品；只有答对才将该词记为“听懂”。先选择尚未听懂的词，四词都听懂后可继续巩固。
- “找到苹果”来自苹果听辨正确；“询问牛奶”和“结账询价”来自孩子的实际表达。结束会话时不能提交任意任务完成列表。
- 文本表达记录“句中使用”，不会记为“主动说出”。语音识别生成的表达可记为“主动说出”；词汇状态只向掌握方向推进。
- 下一句练习优先选择三阶段掌握较少的词；全部完成后轮换四个商品，避免总是重复第一个。
- 家长报告加入按家庭时区计算的近七天练习次数、完成次数与分钟数。

## 语音与隐私

语音识别由单独家长开关控制，默认关闭。开启后，若浏览器支持 Web Speech，儿童可点按麦克风，核对识别文字后发送；浏览器服务可能处理语音。Beta 不保存录音，保存发送后的识别文字。语音不可用时仍可输入文字。AI 伙伴仍由 `allow_ai` 独立控制。
