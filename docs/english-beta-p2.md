# 英语星球 Beta · P2

P2 新增「餐厅星球」作为 Beta 内的第二场景。儿童可在空闲时选择超市或餐厅；若已有未到时的会话，仍续接原场景，避免重复建立会话。超市已有会话、词汇与任务记录保持可读。

## 跨场景学习

餐厅使用 `water`、`bread`、`milk`、`apple`；其中后三个词与超市共享同一儿童的掌握状态。餐厅有独立的听辨水、点餐、询问账单任务。伙伴提示、模拟回复、听辨目标和下一句练习都按当前场景选择。家长报告显示每个场景的会话次数，以及在两个场景中都留下听辨或表达证据的词。仅有旧词汇状态、没有第二场景证据的词不会列入迁移报告。

## 数据与发布

新增迁移 `2026_10_25_130000_create_english_beta_word_evidence.php`，只创建 `english_beta_word_evidence` 表，记录家庭、儿童、会话、场景、词汇、掌握维度与来源。它不回填 P0/P1 的历史会话；报告从 P2 开始积累跨场景证据。该迁移依赖 P0 的四张 Beta 表，发布时应先执行 P0 迁移，再执行 P2 迁移。P1 无数据库迁移。

当前本地开发库还存在两条与 Beta 无关的待执行迁移，本轮未更改开发库。生产未部署。发布前按现有流程核对目标主机、备份、待执行迁移及家长和儿童的实际会话。测试数据库中已验证两场景、共享词汇、任务隔离与迁移报告；浏览器和设备交互仍需实测。

## 回滚

先关闭家庭的 Beta 星球开关。若只撤回 P2，回退 P2 代码，保留 P0/P1 数据；若不再需要证据，先备份 `english_beta_word_evidence`，再仅回滚 P2 迁移。若要删除整个 Beta，先回滚 P2 迁移，再按 `english-beta-p0.md` 回滚 P0 的四张表。不要对整套数据库执行无范围的回滚。
