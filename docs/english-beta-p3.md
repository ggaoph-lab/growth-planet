# 英语星球 Beta P3：语音伙伴

## 使用流程

家长在 Beta 设置中开启 AI 与语音伙伴、选择 Qwen，并在现有 AI 设置中配置 Qwen API Key。孩子在超市或餐厅会话中录制最长 15 秒的英语，服务器将短录音发送给 Qwen3-ASR-Flash 转写。孩子看到转写文字后确认并发送，伙伴回复后自动朗读。文字输入和模拟伙伴继续可用；缺少密钥时显示文字回退。

录音限制为 2 MB，不写入数据库或对象存储。会话中只保存孩子确认发送的文字；转写草稿保留两分钟，一次使用，过期草稿在后续转写时清理。只有有效语音草稿可以增加“主动说出”状态。孩子修改转写文字后按文字输入处理。家长关闭语音或 AI 后，旧草稿不可再用。

录音会经 Growth Planet 服务器传给 Qwen。首次使用时浏览器需要麦克风权限；浏览器须支持 MediaRecorder，并能提供 WebM 或 MP4。生产环境还需确认所用浏览器的安全上下文及 Qwen 服务可达。豆包语音服务仍是预留入口。

## 迁移与回滚

先按顺序执行 P0、P2、P3 迁移。P3 增加独立 `english_beta_voice_drafts` 表，不改旧英语探索、积分或奖励表。关闭家长语音开关可以立即停止新录音和草稿使用。数据库回滚 P3 时只回滚 `2026_10_26_120000_create_english_beta_voice_drafts.php`；需先部署去除 P3 语音接口的代码。回滚会删除未使用的转写草稿，不删除已确认的会话记录。

## 验证范围

自动测试覆盖默认关闭、Qwen 转写请求、一次性草稿、伪造 speech 标记和词汇掌握。前端进行 lint、类型检查及构建。真实 Qwen 账户、儿童设备麦克风和生产网络仍需部署后验证。
