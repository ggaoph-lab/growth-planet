# 英语星球 Beta P4：家长洞察与每周练习计划

家长报告按孩子显示本周练习天数、目标天数、剩余天数、会话与结束次数，以及听懂、主动说出、句中使用的词汇数量。周一到周日依家庭时区计算；只有听辨成功或发送表达的日期才计为练习日，单纯打开场景不计入。现有家长设置可调整每周目标天数和建议每次分钟数。

系统根据本周实际练习较少的场景和当前掌握较少的词，生成下一次场景与词汇建议。儿童在选场景时也会看到同一建议，仍可自由选择场景。建议由已有 Beta 记录确定，不调用额外模型，不产生新的奖励或积分。

P4 无数据库迁移。回滚时撤回 `WeeklyPlan` 服务及家长、儿童页面相关显示和接口字段；已有 P0–P3 会话、词汇及设置数据保持原样。生产部署前仍需在目标环境确认现有 Beta 迁移、家庭时区及多孩子报告。自动测试覆盖未互动不计天、真实听辨计天、较少练习场景推荐和家庭隔离；前端通过 lint、类型检查与构建。实际浏览器和设备交互仍需部署后验证。
