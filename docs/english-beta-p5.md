# 英语星球 Beta P5：移动端语音体验

P5 修正语音链路在手机 Chrome 和 iPad Safari 上的边界行为。开始录音前停止正在播放的朗读，并在孩子点按时预先解锁播放，以便服务器回复后自动朗读。等待麦克风授权时避免重复发起请求；孩子可取消录音，切换页面或将页面移到后台也会取消并释放麦克风。取消的录音不会上传。录音过短、格式不支持或转写失败时，仍可用文字输入。

iPad Safari 通常提供 MP4/M4A 录音，而当前 `qwen3-asr-flash` 的格式列表不包含这两种格式。P5 在浏览器内将 MP4 短录音解码并转换为 16 kHz 单声道 WAV，再上传到现有 Beta 转写接口。WebM 原样上传。音频仍只在请求期间处理，不持久保存。语音按钮仅在安全上下文、麦克风 API、兼容录音格式以及必要的音频转换 API 均可用时出现。

## 验证与未完成的设备检查

本地前端测试使用模拟麦克风验证了取消、离开页面、授权等待时取消、转写发送及回复朗读；另验证了 MP4 到 WAV 的输出格式。后端 Beta 测试、前端 lint、类型检查和构建需作为合并门槛。

本次没有完成真实手机或 iPad 的端到端验证：Android 调试桥没有连接设备；本机未提供可用的 iOS 模拟器。2026-10-26 为本地预览单独执行了 P0、P2、P3 的 Beta 迁移，以及现有登录所需的 `is_site_admin` 迁移；无关的百科奖励策略迁移仍待执行。本地浏览器已确认登录页和 Beta 路由可访问，但尚未用真实儿童设备与 Qwen 密钥验证语音。发布前应在实际 HTTPS 来源，用家长同意的测试家庭与 Qwen 密钥逐项验证：麦克风授权、WebM 与 iPad WAV 上传、转写确认、伙伴自动朗读、取消不上传、后台切换停止录音、权限拒绝与文字回退。不要把本地构建或模拟测试当作设备验证。

P5 无数据库迁移。回滚只需撤回儿童页面录音控制和 `englishBeta/audio.ts` 转换代码；P0–P4 数据与设置不变。P3 的录音开关可随时关闭，立即隐藏语音入口。
