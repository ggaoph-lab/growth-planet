# 英语星球 Beta AI 评分

家长在英语星球 Beta 设置中开启「结束练习时用 Qwen 评分」，配置满分积分和满分金币（各 0–100）。默认关闭、满分奖励为 0，因此升级不会自动发奖。评分独立于伙伴的模拟/Qwen 模式，但需要家庭已配置 Qwen API Key。密钥只留在现有加密设置中。

结束时，服务端把本次孩子与伙伴的文字对话及任务完成状态交给 Qwen；只评价文字表达，不评价录音发音。得分为 0–100，实际奖励按 `round(满分奖励 × 得分 / 100)` 分别计算。例如满分各 10、得分 90，发 9 积分和 9 金币。实际发放走现有奖励策略与两种账本，按会话 ID 去重。分数、家长当时的满分设置和实际入账数都保存在会话中。

没有孩子发言、未启用评分、缺密钥或模型故障时不会发奖；家长报告显示评分状态。过期自动关闭的会话不评分。评分仅在孩子主动结束会话时触发。

迁移：`php artisan migrate`。回滚代码前，先在家长设置中关闭评分；若需回滚数据库结构，先备份会话与奖励记录，再回滚 `2026_10_26_000001_add_scoring_to_english_beta_sessions`。回滚迁移会丢失会话评分字段，不会撤销已入账的奖励；若需撤销奖励，应按现有账本冲正流程处理。
