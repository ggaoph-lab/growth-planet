# 英语探索：每日学习与复习

适用基础：认识常用词、可以理解简单短句的小学低年级孩子。

## 已实现

- 在原有观看登记上方加入每日学习卡，18 项固定内容覆盖水果、餐桌、动物、颜色、书包、心情。每组两个词配一个短句。
- 每天最多引入 3 项新内容，优先安排到期复习，每天最多完成 8 项。按家庭时区计算日期，按孩子独立保存。
- 新内容先看英文、中文提示和插图，可以点击英语神经语音跟读（系统朗读只在语音服务不可用时兜底）；随后隐藏提示，选择中文意思。复习改为看中文选英文。
- 答错展示正确表达，不扣分；尽可能穿插另一张卡后再出现。答错重置复习阶段；答对依次间隔 1、3、7、14 天，之后继续每 14 天复习。这是可调整的初始规则，不把选择题通过等同于口语掌握。
- 每项每天首次答对默认 2 XP + 1 金币，进入原有账本；每日最多 8 项。服务端判题、事务、按孩子加锁、唯一奖励键和接口幂等共同避免重复发放。
- 家长关闭奖励策略时照常学习但不发奖；将该策略设置为需要审核时暂停自动发奖，当前版本不创建练习审核单。
- 无新内容或当天额度用完时显示完成页，引导离开屏幕，用一句英语与家人交流。

## API 与存储

`GET /api/v1/kid/english/learning` 获取当前任务及进度。

`POST /api/v1/kid/english/learning/answer` 提交 `key` 和 `answer`，需要 `Idempotency-Key`。返回判题结果、实际奖励、下次复习日期和最新任务。

内容位于 `backend/config/english_learning.php`，内容 key 应保持稳定。新增表 `english_learning_progress` 和 `english_learning_answers`。奖励策略为 `english.practice`。

## AI 的下一阶段用途（尚未接入）

固定课程与复习不依赖任何模型服务。难易程度也不在每次学习时由模型临时判断：新增内容时，模型可以给候选卡片标注类型（单词、短句、语法）和大致等级，家长确认后才进入课程。每天仍然先排到期复习，再按已掌握的前置内容引入下一项；孩子自己的对错继续决定 1、3、7、14 天的复习间隔。

语法等后续内容使用新的题目类型，不与每天最多 3 项新单词挤在同一额度里。模型只能用孩子已经学过的词来起草，经结构和内容检查后由家长发布。更值得增加的是围绕已学词汇生成短故事、替换情境练习和限定主题对话，而不是无边界聊天。

实施时由后端封装供应商接口，密钥只放服务端；先生成候选内容，经结构、词汇难度和内容检查后供家长确认，再发布给孩子。模型不可修改奖励或决定金币。只发送练习需要的词汇与等级，不发送孩子身份和完整学习档案；模型失败时回退固定课程。费用上限、超时、缓存和家长开关应与接入一起实现。

口语反馈需要单独设计录音授权、保存期限和评分规则；本版只提供朗读与跟读，不录音、不声称评估发音。

## 验证

新增后端测试覆盖奖励去重、家庭时区跨日、复习间隔、错题重学、新课与每日上限、孩子进度隔离、奖励关闭及接口幂等。前端测试覆盖隐藏提示、等待判题、防重复点击、错题反馈和加载重试。
