# 英语知识点映射试验

每日新词 AI 请求附带一个可选的学习重点。第一阶段聚焦常见类别和反义词；当已会词表包含至少三个基础词后，转向把新词与熟悉词和日常情境联系起来。年龄和难度判断、已会词排除、每日十词及复习规则继续由原有英语模块负责。此映射只是选词提示，不代表孩子通过了知识点评估；无 AI 时本地词梯照常工作。

映射参考 **Marble Skill Taxonomy v1** 的 `mt_oL9s_bufDp` 和 `mt_6-MYToNZ39`。候选词及阶段阈值由成长星球自行编写，需要根据实际学习效果调整。原始数据见 [Marble Skill Taxonomy](https://github.com/withmarbleapp/os-taxonomy)。© Generative Spark, Inc. (Marble)，数据库采用 ODbL 1.0，文本内容采用 CC BY-SA 4.0。当前没有复制其题目、描述或教学研究文本，也没有导入标准目录。

试验观察重点：每日十词完成率、重复或过难词的比例、复习答对率，以及孩子能否在故事或口语中使用新词。只有这些数据有改善，才继续扩展知识点映射。
