# 成长星球 — 安全与隐私（V1.0）

## 1. 威胁模型

| 威胁 | 例子 | 对策 |
|---|---|---|
| 孩子越权 | 修改请求访问家长接口、给自己加金币、批准自己的兑换 | 路由角色中间件 + Policy；孩子会话没有任何家长接口 |
| 猜测其他孩子 ID | `/kid/movies/123`、改 `child_id` 参数 | 孩子接口从会话取 `child_id`，不接受客户端传入；其他资源 404 |
| 不适龄内容泄漏 | 孩子直接请求电影/视频详情、搜索联想、缩略图 URL | 后端 `ContentVisibility` 查询层强制白名单；不可见即 404；图片由本站鉴权提供 |
| 外部内容注入 | TMDB 标题含脚本、恶意链接 | 外部数据视为不可信：纯文本存储、Vue 转义、URL 域名白名单 |
| 撞库 / 暴力破解 | 家长密码、孩子 PIN | 限流 + 递增锁定；PIN 只在授权设备有效 |
| 重复/并发提交 | 连点领奖、并发兑换 | 幂等键 + 业务唯一键 + 行锁 + CHECK 约束 |
| 密钥泄漏 | TMDB Key 出现在前端 | 只在后端 `.env`；前端无任何第三方密钥 |
| 数据泄露 | 备份、照片外泄 | 备份加密；私有存储 + 鉴权下载；EXIF 去除 |

## 2. 认证

### 家长
- 用户名/邮箱 + 密码；密码 ≥ 10 位，Laravel `Hash`（bcrypt/argon2id）。
- 登录限流：账号+IP 每 15 分钟 5 次；账户失败计数递增锁定（5 次后 1 分钟，之后翻倍，最长 60 分钟）。
- 会话 Cookie：`HttpOnly`、`SameSite=Lax`、生产 `Secure`；登录后重新生成会话 ID。
- **无默认账号与密码**：首位家长通过 `php artisan family:create` 交互创建。

### 孩子
- 家长在设备上执行"授权为孩子设备"（需二次验证）→ 服务端生成 32 字节随机令牌，写入 `HttpOnly` Cookie（`gp_device`，400 天），数据库只存 SHA-256。
- 孩子选择头像 + 输入 4–6 位 PIN（家长可关闭 PIN，此时仅依赖设备授权）。
- PIN 限流：设备+孩子每 10 分钟 5 次。
- 撤销设备后，该设备上的孩子登录立即失效（每个孩子请求都校验设备 Cookie 仍有效）。
- 孩子登录后进入家长后台必须重新输入家长账号密码。

### 二次验证（Sudo）
- `POST /auth/confirm-password` → 会话记录 `sudo_until`（默认 10 分钟，设置可调）。
- 保护：修改时区、修改生日、修改 PIN、设备授权/撤销、奖励策略与额度修改、积分冲正、手动奖励、内容安全审核、导出、删除数据。

## 3. 授权（全部在后端）

1. `auth:sanctum` → 2. `role:parent|child` 中间件 → 3. 家庭作用域（查询从当前家庭出发） → 4. Policy / 孩子接口强制使用会话中的 `child_id`。

自动化测试遍历路由表，断言所有 `/api/v1/parent/*` 对孩子会话返回 403、对游客返回 401。

## 4. Web 安全

| 项 | 措施 |
|---|---|
| CSRF | Sanctum 有状态 SPA；同源部署 |
| XSS | Vue 默认转义；ESLint `vue/no-v-html: error`；后端存纯文本 |
| CSP | `default-src 'self'; img-src 'self' data: blob:; script-src 'self'; style-src 'self' 'unsafe-inline'; connect-src 'self'; frame-ancestors 'none'; object-src 'none'; base-uri 'self'` |
| 安全头 | `X-Content-Type-Options`、`Referrer-Policy: same-origin`、`Permissions-Policy`、生产 HSTS |
| SQL 注入 | Eloquent/查询构造器参数绑定；排序与筛选字段白名单 |
| 输入验证 | 所有接口使用 FormRequest；长度上限；枚举校验；日期合法性 |
| 批量赋值 | `$fillable` 白名单；`family_id`、`role`、余额永不可批量赋值 |
| 限流 | API 每用户 120 次/分钟；登录/PIN/二次验证单独限流 |
| 文件上传 | MIME 嗅探 + 扩展名白名单、大小限制、重新编码去 EXIF、随机文件名、私有目录 |

## 5. 内容安全（电影）

- **默认拒绝**：新入库内容状态为 `PENDING`，孩子不可见。
- 可见条件在 SQL 中组合（见 database.md §10、§11），任何孩子端接口（列表、搜索、详情、图片、相关推荐、申请状态、**系列详情与统计**）都复用同一个查询作用域。
- 年龄按出生日期 + 家庭时区当日动态计算；生日修改需二次验证并写审计。
- 分级资料不完整 → `INSUFFICIENT_INFO`，不开放。
- 不依赖 TMDB `adult` 字段；不声称存在完整的中国大陆官方年龄分级数据。
- 孩子对未审核电影只能提交纯文字请求；家长在后台检索 TMDB，结果不返回孩子端。
- 外部图片由后端下载、校验、重新编码、本地存储，孩子端只加载本站图片 URL。
- **电影系列防泄漏**：只批准第一部时，孩子端不得出现第二部的标题、海报、简介，也不得通过 `movie_count`、进度分母、搜索联想或系列 API 推断存在续集；系列偏好（收藏/屏蔽）不能绕过单片白名单。
- 英语星球不接入任何视频平台：孩子只能从家长维护的节目清单中选择登记，自填内容仅限可选的单词（长度、数量受限，纯文本存储）。自报的时长和奖励必须经家长确认，后端校验登记日期、时长范围与每日上限。

## 6. 儿童隐私与数据最小化

| 规则 | 实现 |
|---|---|
| 收集范围 | 昵称、内置头像、出生日期、年级、主题色；不收集真实姓名、身份证、学校、住址、电话、定位 |
| 出生日期 | 仅家长可设置；数据库加密存储（`encrypted` cast，依赖 `APP_KEY`）；API 只对家长返回完整日期，孩子端只返回年龄 |
| 传输 | 生产强制 HTTPS |
| 第三方 | 不接入广告与分析 SDK；前端不加载外部 CDN、字体；TMDB 请求只包含检索词，不包含任何孩子信息 |
| 日志 | 不记录密码、PIN、Cookie、生日；IP 保留 90 天 |
| 导出与删除 | 家长可导出与删除孩子数据（第六阶段） |
| 开发测试 | 测试与演示数据全部虚构并明确标注；`DemoSeeder` 在生产环境拒绝执行；不把真实儿童资料上传到第三方服务（包括 AI 工具） |

> ⚠️ `APP_KEY` 丢失将导致出生日期无法解密。部署文档要求将 `APP_KEY` 与加密备份口令一起离线保管。

## 7. 密钥与环境变量

- `.env` 不入库，只提供 `.env.example`（占位值）。
- `app:preflight` 命令在生产环境检查：`APP_DEBUG=false`、`APP_KEY` 已设置、数据库密码非占位值、`SESSION_SECURE_COOKIE=true`。
- `TMDB_API_KEY` 只在后端读取，未配置时电影资料降级为手动录入并在界面说明。

## 8. 审计

`audit_logs` 只追加（数据库触发器禁止修改/删除）：登录成功/失败/锁定、二次验证、设备授权/撤销、孩子档案与生日/PIN 修改、时区修改、积分冲正、审核操作、内容安全审核、导出、删除。

## 9. 备份

`mysqldump --single-transaction --routines --triggers` + 附件目录 → 加密（`openssl enc -aes-256-cbc -pbkdf2` 或 `age`）→ 保留 14 日备 + 8 周备；提供恢复与恢复演练脚本（第六阶段完成，第一阶段提供基础 `backup.sh`）。
